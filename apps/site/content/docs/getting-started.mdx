title: Getting started
description: Build the Anchor program, run the tests and start the local stack.
---

The tested platform is Nix on x86_64 Linux. `flake.lock` pins Anchor 1.2.0, Solana CLI 4.0.3 and the host tools; `shell.nix` uses the same lock.

<Callout type="info">
  First setup needs network access and several GB of disk space. On NixOS, the
  upstream platform-tools executables require `nix-ld`.
</Callout>

<Steps>
<Step>

### Enter the pinned shell

```sh
nix-shell
bash scripts/check-nix-path.sh
```

</Step>
<Step>

### Bootstrap and build

```sh
bash scripts/bootstrap.sh
bash scripts/build.sh
```

Bootstrap installs `cargo-build-sbf` 4.3.0 under the ignored `.tools/` directory. The build produces `target/deploy/forge.so`, `target/idl/forge.json` and `target/types/forge.ts`.

</Step>
<Step>

### Run the tests

```sh
cargo test --locked -p forge
cargo fmt --all -- --check
cargo clippy --locked -p forge --all-targets -- -D warnings
```

The tests execute the compiled `target/deploy/forge.so` in LiteSVM. Rebuild after every program change.

</Step>
<Step>

### Run the reproducible fixture

```sh
cargo test --locked -p forge --test vault create_and_fund_exact_test_token_balance -- --exact --nocapture
```

It creates in-memory treasury and approver wallets, issues the test supply, creates the vault and funds it. Expected balances: treasury `0`, vault `10000000000` base units (10,000 `FORGE_TEST_USD`).

</Step>
</Steps>

<Callout type="warn">
  Do not use `anchor test` as a deployment-free command: it deploys
  automatically.
</Callout>

## Workspace

The Bun and Nx workspace builds and checks the program, the SDK, the API, the console, the local tooling and this site:

```sh
nix-shell
bun install --frozen-lockfile
npx nx run-many -t build
npx nx run-many -t check-types test
bun run check
```

Use `--parallel=1` on memory-constrained machines. API tests need the local PostgreSQL (`bash scripts/localnet.sh pg-up`).

## Local stack

Everything binds to loopback where the tools allow it and keeps state under the ignored `.local/` directory. The validator loads the built program at genesis.

```sh
nix-shell --run 'bash scripts/build.sh'           # program + IDL
nix-shell --run 'bash scripts/localnet.sh up'      # PostgreSQL :54329 + solana-test-validator :8899
bun run --cwd packages/sdk build
bun run --cwd apps/localnet seed                   # demo wallets, mint, institutions
bun run dev:api                                    # API :3002 + worker
bun run dev:console                                # console http://127.0.0.1:3003
bun run e2e                                        # scripted end-to-end validation
nix-shell --run 'bash scripts/localnet.sh down'    # or `reset` to delete all local state
```

<Callout type="warn">
  `solana-test-validator` binds RPC, websocket and faucet to all interfaces and
  has no option to restrict them. Keep a host firewall in place.
</Callout>
