The FORGE program is deployed on Solana Devnet for demonstration. Devnet uses test SOL and the `FORGE_TEST_USD` fixture mint only. There is no mainnet deployment.

<Callout type="warn" title="The upgrade authority can replace the program">
  The program uses the upgradeable loader. Its upgrade authority can replace the
  program at any time, so the deployed program is not immutable.
</Callout>

## How the deployment was checked

- `solana program dump` returned bytes with the same SHA-256 as the local `target/deploy/forge.so`.
- A simulated `create_vault` with a made-up mint executed the program and failed on `AccountNotInitialized` (3012) for that mint, so the declared id matches the deployed address.

## Demo fixtures

The demo wallets and the test mint were seeded on Devnet on 12 October 2026. Because the public faucet rate-limits airdrops, the seed keeps the role wallets in a local file and pays the approvers and the borrower from a treasury funded by hand.

| Fixture | Address |
| --- | --- |
| Treasury, also the mint authority | `7JBFmF73kkJc6vrRebntKYCNbjV4UqiKrXkGq1sk7SVQ` |
| `FORGE_TEST_USD` mint | `EaobAHzbHXAoWdqBbvyQCWxU1PAZZF3SuGmAoYM1Zhv5` |

The mint has six decimals and no freeze authority. Its supply is 10,100 test tokens: 10,000 for the treasury to fund the vault and 100 for the borrower's interest. The treasury keeps mint authority and can issue more.

## Running against Devnet

`scripts/devnet.sh` deploys the program and runs the API and worker against Devnet. The steps, funding requirements, the fixture seed and the rehearsal record are in [`docs/devnet.md`](https://github.com/qoppalabs/forge/blob/main/docs/devnet.md).

Not covered yet: shared-demo signing. The console's demo signing holds keys in the browser; on a shared Devnet demo, signers should use their own wallets.
